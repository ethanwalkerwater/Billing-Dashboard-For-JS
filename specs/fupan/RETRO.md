# 课堂复盘首次发布复盘

## 验收边界

正式地址为 https://app.jsjy.asia/fupan 。本次采用正式域名、生产网关、私有数据库和实际构建产物验收。桌面和移动端的完整人工操作使用虚构课程与测试音频。主管名单仍为空，实名主管扫码后从真实事项跳到原音是待业务方参与的一项验收。

## 本次遇到的问题

| 问题 | 可能影响 | 已落实的改动或验证 |
|---|---|---|
| 共享云函数在本次开发前刚发布过工作台功能 | 从旧分支构建会回退学员档案功能 | 下载生产函数，比对到对应提交；修改前重新构建并逐字节比对，发布前再下载核对，发布后再次比对生产和本地文件。 |
| 从其他后台沿用网址片段中的登录凭证，会让登录链接可以被转发 | 私有实课被错用身份访问，操作人记录失真 | 飞书登录绑定发起浏览器的一次性状态，回调签发限路径 HttpOnly Cookie。独立主管授权每次校验，撤销再开通也会更换授权编号。补测跨浏览器回调、跨站写入、撤权及名单外身份。 |
| 搜索词和按姓名拼出的档案编号会落入网址 | 网关日志或浏览器历史留下师生姓名 | 姓名搜索走 POST，课表身份采用摘要。业务日志只保留路由和不可逆的身份、目标索引。 |
| 转写修订、补传录音会改变待复核依据 | 跟进人员可能找不到原任务，旧结论可能重复计入老师统计 | 当前依据与旧版人工记录分开查询，增加改版、补传和结案的数据库回归。 |
| TypeScript 检查不能发现 PostgreSQL 的保留字或视图列不匹配 | 迁移可能在生产运行到一半才失败 | 临时 PostgreSQL 17 加载真实迁移，并用虚构课表与课程验证状态竞争、权限、规则和统计。网页验收针对最终打包产物。 |

## 下次发布

在录课模块运行 `npm run check:fupan`。具备 PostgreSQL 工具且使用非 root 账号时，数据库回归会创建独立的本地实例。浏览器回归使用已安装的 Chrome，也可通过 `CHROME_BIN` 指定。发布共享函数前先保存现网构建并确认其对应基线，发布网页只传独立的 fupan 目录。

开通首位主管后，实际扫码、回听一个证据片段，再记录一次业务上真实需要的判断。每周查看待复核积压、排除原因、失败课程数和新增数据库活跃时段。依据实测校准预算。
