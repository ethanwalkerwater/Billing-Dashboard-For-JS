# 薪资业务规则

本文档记录 `packages/billing-core/src/payroll-core.js` 已实现的当前口径。修改公式时，必须同步修改内核测试和本文档。

## 总公式

```text
课时反馈奖金 = Σ（明细总金额 × 折扣% × 乘数）
学员介绍提成 = 归属学员当月学费 × 20%
服务/管理奖金 = 服务学员当月学费 × 7%
固定收入 = 基础薪水 + 管理费 - 房租扣除
Bonus 薪水 = 课时反馈奖金 + 介绍提成 + 服务奖金 - 基础薪水 × 1.2
实际计入 Bonus = max(Bonus 薪水, 0)
个人总收入 = 固定收入 + 实际计入 Bonus + 补贴报销 - 个人五险 - 个税
公司总成本 = 固定收入 + 实际计入 Bonus + 补贴报销 + 公司五险
```

Bonus 公式结果保留负数用于复核课时是否达标；实际发放与公司成本计算时，负数按 0 计入。

## 课时费

- 优先使用课表中的 `课程总价格`。
- 金额缺失时，按 `课程单价 × 课程时长 × 取消比例` 回退计算。
- 取消比例与课时账单共享同一份 `CANCELLATION_RATES`。
- 网页课时明细的实际金额为 `总金额 × 折扣% × 乘数`。
- 乘数默认自动读取该老师当月课时系数（例如 62% 对应 `0.62`）；手动输入可覆盖，清空后恢复自动。
- 课时反馈奖金直接取所有明细实际金额之和，Bonus 区域不再重复乘课时系数。
- 乘数只影响授课老师课时费和由此计算的课时反馈奖金，不影响学生归属与服务提成基数。
- 市场推广、教学顾问、排课、行政前台字段只保留维护，不进入收入公式。

## 当月评分与反馈系数

| 老师类型 | 规则 |
|---|---|
| 全职 | 基础 47%；学习提升、责任心、个人魅力每有一项进入全职老师前 50%，增加 5%，最高 62% |
| 兼职 | 默认 60% |
| 全职且缺少任一当月评分 | 按全职 0 项前 50% 处理，即使用基础 47%，并给出醒目提醒 |

评分必须按工资月份单独上传，不读取 Parent Report 使用的历史累计评分。每个月的前 50% 独立计算：
人数使用 `floor(该月评分完整且在基础薪水表标记为全职的老师数 × 0.5)`。边界分数并列时，
同分老师都进入该指标的前 50%。兼职老师不参与排名，也不要求上传评分。

## 提成

- 学生姓名会去掉末尾编号，再与学生归属表匹配。
- 同一老师同时是归属老师和服务老师时，两项同时计入，合计 27%。
- 学生当月学费为负数时，提成基数按 0 处理，不生成负提成。

## 缺失数据

- 缺基础薪水：按 0 计算并提醒。
- 缺报销：按 0 计算并提醒。
- 缺五险个税：相应金额按 0 计算并提醒。
- 全职老师缺少当月评分：按全职基础系数计算并提醒。
