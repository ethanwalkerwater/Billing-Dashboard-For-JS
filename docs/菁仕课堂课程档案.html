课程档案：从单节学情报告到课程长期报告

记录于 2026-10-16 · 方案 A 已上线，方案 C 待讨论后推进

每节课的学情报告只回答「这节课怎么样」。课程档案要回答「这门课学到哪了、哪些知识点稳了、离考试还差什么」：按学生 + 课程建档，每节课的学情自动累加，对照考纲展开成整门课的进度。

一、已决定的推进顺序

方案内容状态
A. 单课报告加图表课堂时间分布时间轴（复习 / 讲解 / 例题 / 练习 / 答疑 / 总结 / 其他）、知识点用时占比、学生主动提问板块已上线提示词 v3
B. 不按考纲的档案把历次报告的知识点按名字直接累加不做知识点名字每次不一样，累加不起来
C. 按考纲的课程档案考纲知识点库 → 每节课对应到考纲编号 → 档案页按章节展示进度、状态和历次依据待讨论先挑一门课试点

方案 A 做了什么（2026-10-16 上线）

  • 提示词：学情报告多输出 timeline（每个环节的类型、起止时间、讲到的知识点）和 questions（学生主动提的问题、时间、老师怎么回应）。后台提示词发布为 v3，在 v2（你改过的家长总结）基础上只加了这两条要求。
  • 程序校验：时间不合法的环节丢掉、重叠截断、知识点只认本课「掌握情况」里有的名字；旧报告和旧提示词没有这两项时，对应板块不显示。
  • 知识点用时由程序按时间轴算（一段讲了几个知识点就平分这段时间），不让大模型估分钟数。
  • 页面：报告从 6 个板块变成最多 9 个：本课学习内容 → 课堂时间分布 → 知识点用时 → 知识点掌握情况 → 主动提问（有才显示）→ 课堂表现 → 易错点 → 巩固计划 → 下节课衔接。PDF 由原来固定 2 页变为约 3 页，去掉了强制分页。

方案 A 的时间轴和知识点用时，就是方案 C 的原材料：每节课「哪个知识点讲了多久、掌握到什么程度、依据是什么」都已经结构化存下来了。

二、方案 C：按考纲的课程档案

1. 档案怎么建

  • 一份档案 = 学生 + 课表里的「课程类型」，如「浩然 · IG物理」「浩然 · Alevel数学」。课表里的课程类型目前有 IG物理、Alevel物理、IG数学、Alevel数学、雅思写作、英语刷题班等 30 多种。
  • 有考纲的课（IG / Alevel 各科）按考纲展开进度；没有固定考纲的课（刷题班、雅思）先只做「历次课程汇总 + 反复出现的易错点」，以后再设计各自的技能树（如雅思按四项评分标准）。
  • 转写一直保留（录音 30 天后删除），所以档案可以随时用全部历史课重算。

2. 考纲知识点库

每门课一份考纲树，存数据库，后台可看可改。以 Cambridge IGCSE Physics（0625）为例，初稿由我按官方考纲整理，需要物理老师核对：

实际使用时每个编号下还会细到考纲条目（如 1.5.2 牛顿第二定律），档案按条目累计、按章节汇总。

3. 每节课怎么对应到考纲

  1. 出报告时，把这门课的考纲条目列表一起给大模型，要求 mastery 里每个知识点只能从列表里选编号（不能自己起名字），时间轴的 points 同理。这样「牛顿第二定律」和「F=ma」都会落到同一个编号上。
  2. 对应不上的内容（考纲外的拓展、学校作业）记为「考纲外」，不计入进度。
  3. 老师可以在后台改某节课的对应关系，档案跟着重算。

4. 状态怎么累加

档案状态规则
未学没有任何一节课讲到
学过讲过，最近一次是「本课已学习」或「开始运用」
已掌握最近一次是「基本掌握」，且之前没有连续两次「需要巩固」
需巩固最近一次是「需要巩固」，或同一易错点在两节以上课里出现

只看「最近一次」是为了让进步能体现出来；规则写在代码里，不让大模型判断整门课的状态。

6. 要做的事（试点一门课）

  1. 建表：考纲树（课程类型 → 章节 → 条目）、课时与考纲条目的对应记录。
  2. 整理试点课程的考纲初稿 → 老师核对 → 导入。
  3. 学情报告提示词加「只能从考纲列表选编号」，对这门课生效；其余课不变。
  4. 用已有转写回填历史课。
  5. 档案页（网页，同报告风格，可打印 PDF）+ 后台入口；App 课程详情里加「课程档案」链接。

三、待你决定

  • 试点课程IG物理（考纲最清晰，推荐）/ Alevel数学（课最多）/ 其他
  • 谁能看先给老师和后台看，内容稳定后再开放给家长（推荐）/ 一开始就给家长链接
  • 学生识别课表「学生」字段是否会重名？会的话改用「学员课程ID」区分
  • 考纲核对由哪位老师核对试点课程的考纲初稿

四、风险与成本

  • 对应准确度：一节课常跨多个考纲条目，大模型可能选错编号。缓解：限定只能选列表里的编号 + 老师可改 + 只看最近一次状态。
  • 转写质量：录音嘈杂时知识点判断会偏。档案页注明「依据课堂录音整理」，每个状态都能点开看到判断依据。
  • 成本：每节课多带一份考纲列表（约 2–4 千字），大模型费用增加不到 1 分钱；档案页按需计算，不加定时任务。
